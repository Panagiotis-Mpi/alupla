## Overview
ALUPLA is a full-stack alumni management platform designed to support data entry, administration, statistical analysis, and geographic visualization of graduate records. The platform provides role-based access for administrative users, public access to anonymous statistics, and bilingual support in Greek and English.

### Key Features
* **Graduate Management:** Create, edit, delete, search, filter, import, and export alumni records.
* **Statistics Dashboard:** Anonymous KPIs, charts, and export options for alumni data analysis.
* **Interactive Map:** Geographic visualization of alumni distribution in Greece and abroad.
* **Role-Based Access:** Separate permissions for Secretariat users and Super Admins.
* **Internationalization:** Full Greek and English interface support.
* **Accessibility:** Built-in accessibility panel for font size, contrast, and link highlighting.

## Tech Stack
* **Frontend:** React, TypeScript, Vite
* **Styling:** HTML, CSS
* **Routing:** React Router
* **Charts:** Chart.js, React Chart.js 2
* **Maps:** Leaflet, React Leaflet
* **Internationalization:** i18next, react-i18next
* **Backend:** Node.js, Express, TypeScript
* **Database & ORM:** PostgreSQL, Sequelize
* **Authentication:** JWT
* **File Handling:** Multer, XLSX
* **Deployment:** Vercel, Render, Neon PostgreSQL
